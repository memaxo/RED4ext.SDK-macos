## Exact Install Paths

The SDK searches for `cyberpunk2077_addresses.json` in this exact order:

### 1. Environment Variable (Highest Priority)
```bash
export RED4EXT_SDK_ADDRESS_DB=/path/to/custom/cyberpunk2077_addresses.json
```
Useful for:
- Testing new address databases without replacing system files
- Multiple game versions (different DBs for different patches)
- Development/debugging

### 2. Plugin Directory
Same directory as the plugin `.dylib` file:
```
/path/to/game/red4ext/plugins/MyMod/
├── MyMod.dylib
└── cyberpunk2077_addresses.json    ← searched here
```

### 3. RED4ext Root (Relative to Plugin)
```
/path/to/game/
├── red4ext/
│   ├── cyberpunk2077_addresses.json          ← searched here
│   └── bin/x64/cyberpunk2077_addresses.json  ← then here
└── red4ext/plugins/MyMod/MyMod.dylib
```

### 4. Game Executable Directory
```
/path/to/game/
├── Cyberpunk2077.app/Contents/MacOS/Cyberpunk2077
└── cyberpunk2077_addresses.json    ← searched here
```

### 5. RED4ext Root (Relative to Executable)
Same as #3, but relative to the game executable path.

### Recommended Distribution Layout
For mods, ship the DB alongside your plugin:
```
red4ext/plugins/MyMod/
├── MyMod.dylib
├── MyMod.json (manifest)
└── cyberpunk2077_addresses.json
```

## Runtime Parser Behavior

The `UniversalRelocBase::Resolve()` function (in `include/RED4ext/Relocation-inl.hpp`) implements macOS address resolution:

### Database Search Order
1. `$RED4EXT_SDK_ADDRESS_DB` environment variable (highest priority)
2. Same directory as plugin (`.dylib`)
3. `red4ext/` or `red4ext/bin/x64/` relative to plugin
4. Same directory as game executable
5. `red4ext/` or `red4ext/bin/x64/` relative to executable

### JSON Parsing
- **Hash format:** Decimal string (e.g., `"1247874916"`)
- **Offset format:** `"segment:0xOFFSET"` (segment must be `1` for `__TEXT`)
- **Validation:** Parser rejects malformed entries silently (logs to stderr)
- **Failure mode:** First 10 missing hashes logged, then suppressed with warning

### Testing Runtime Behavior

To prove the parser works at runtime:

```bash
# Set the DB path explicitly
export RED4EXT_SDK_ADDRESS_DB=/path/to/cyberpunk2077_addresses.json

# Build and load the smoke test plugin
# (Plugin will resolve all 126 hashes and report missing=0, dup=0)
```

**Success Criteria:**
- Smoke test logs: `Loaded 126 hashes from /path/to/cyberpunk2077_addresses.json`
- Smoke test logs: `Done. missing=0 dup=0`
- Log file: `/tmp/RED4ext.SDK_smoke_test.log`
